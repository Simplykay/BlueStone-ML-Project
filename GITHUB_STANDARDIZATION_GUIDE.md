## ❓ FAQs

**Q: Will changing repository names break my project links?**  
A: No, GitHub maintains 301 redirects automatically for 12 months.

**Q: Can I rename multiple repos at once?**  
A: No, GitHub requires one-by-one renaming through Settings.

**Q: What if I make a mistake in deletion?**  
A: You cannot undo deletion directly. Contact GitHub support for recovery within 90 days.

**Q: Do I need to update local clones after renaming?**  
A: Yes, update `.git/config` remote URLs or re-clone the repository.

**Q: How long does deletion take?**  
A: Immediate on GitHub, but some processes may take 5-10 minutes to complete.
